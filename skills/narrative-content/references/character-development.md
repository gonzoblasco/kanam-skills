## Archetypes

| Archetype | Function | Example |
|---|---|---|
| **Hero** | Drives the story, grows through conflict | Frodo, Luke Skywalker |
| **Mentor** | Guides the hero, provides wisdom | Gandalf, Obi-Wan |
| **Herald** | Announces change, calls to adventure | R2-D2's message, White Rabbit |
| **Threshold Guardian** | Tests the hero's resolve | Cerberus, the shark in Jaws |
| **Shapeshifter** | Unpredictable, keeps hero guessing | Loki, Gollum |
| **Shadow** | Represents the hero's dark side | Voldemort, Darth Vader |
| **Trickster** | Provides comic relief, challenges status quo | Puck, Jack Sparrow |
| **Ally** | Supports the hero, provides skills | Samwise, Hermione |

## Motivation Matrix

| Dimension | Questions |
|---|---|
| **What do they want?** | External goal, conscious desire |
| **What do they need?** | Internal growth, unconscious need |
| **What are they afraid of?** | The thing that would stop them |
| **What would they never do?** | Moral boundary (that they may cross) |
| **What do they believe?** | Core worldview, assumptions |
| **What are they wrong about?** | The lie they need to unlearn |
