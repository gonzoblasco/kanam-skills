# Trademark Basics

> ⚠️ This is not legal advice. For actual trademark registration, consult an IP attorney.

## What Can Be Trademarked

- **Words** — "Apple" for computers
- **Logos** — The Nike swoosh
- **Sounds** — The MGM lion roar
- **Colors** — Tiffany blue (in jewelry context)

## What Cannot Be Trademarked

- Generic terms ("Computer" for computers)
- Descriptive terms without secondary meaning ("Fast" for internet service)
- Deceptive marks (suggesting false origin or quality)
- Confusingly similar to existing marks in same category

## Trademark Classes

Trademarks are category-specific. "Apple" for computers ≠ "Apple" for fruit.

Key tech classes:
- **Class 9:** Software, apps, computers
- **Class 42:** SaaS, cloud services, software development

## Quick Self-Check

Before paying for a trademark search:

1. **USPTO TESS:** https://tmsearch.uspto.gov — search for exact and similar names
2. **WIPO Global Brand Database:** https://www.wipo.int/branddb/ — international
3. **Google:** Search "[name] + [category]" — any active businesses?
4. **App stores:** Search for apps with the same name
5. **Social media:** Check Twitter, Instagram, YouTube handles

## Red Flags

- Same name, same category → likely conflict
- Similar name, same category → possible conflict
- Same name, different category → probably fine (but check fame)
- Famous mark in any category → avoid (dilution risk)

## When to Register

- Before launch if you have budget
- Definitely before raising money (investors check)
- Before expanding internationally
- If you receive a cease & desist (too late, but still)

## Common Mistakes

- Assuming domain ownership = trademark rights (it doesn't)
- Assuming LLC registration = trademark protection (it doesn't)
- Not checking internationally (your .com is global)
- Waiting until you're successful (then it's more expensive)
