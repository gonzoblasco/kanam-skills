# STAR Method Reference - CV Tailor

Guía completa del método STAR para reescribir experiencia laboral.

## STAR Breakdown

| Element | Qué es | Cómo escribirlo |
|---|---|---|
| **S** Situation | Contexto: cuándo, dónde, qué escala | "During a user growth plateau for [Product] (DAU 500K+)..." |
| **T** Task | Tu rol: qué te pidieron, cuál era tu objetivo | "...led the design of a new-user activation funnel analysis..." |
| **A** Action | Qué hiciste: acciones concretas, herramientas | "...optimized 3 critical registration touchpoints + designed a 7-day retention incentive strategy..." |
| **R** Result | Qué pasó: datos, impacto, métricas | "...increasing new-user D1 retention from 32% to 45% and MAU by 18% within 3 months." |

## Action Verbs

| Categoría | Verbos |
|---|---|
| **Leadership** | Led, Directed, Managed, Spearheaded, Orchestrated |
| **Creation** | Built, Designed, Developed, Created, Implemented |
| **Optimization** | Optimized, Improved, Streamlined, Enhanced, Refactored |
| **Analysis** | Analyzed, Evaluated, Assessed, Measured, Audited |
| **Results** | Delivered, Achieved, Generated, Drove, Produced |

## Quantification Guide

| Dimensión | Preguntas guía |
|---|---|
| **Scale** | ¿Cuántas personas manejabas? ¿DAU del producto? |
| **Efficiency** | ¿Cuánto tiempo antes vs después? |
| **Growth** | ¿Revenue / users / conversion rate change? |
| **Cost** | ¿Dinero / headcount / tiempo ahorrado? |
| **Impact** | ¿Usuarios servidos / clients afectados / teams cubiertos? |

## Before/After Examples

**Before:** "Responsible for user growth initiatives"
**After:** "During a user growth plateau (DAU 500K+), led activation funnel analysis, optimized 3 registration touchpoints, increasing D1 retention from 32% to 45% and MAU by 18% in 3 months."

**Before:** "Worked on frontend features"
**After:** "Built 12 reusable React components adopted across 3 product teams, reducing UI development time by 40% and improving Lighthouse accessibility score from 72 to 94."
