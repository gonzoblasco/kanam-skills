# Referencia del Método STAR - CV Tailor

Guía completa del método STAR para reescribir experiencia laboral.

## Desglose STAR

| Elemento | Qué es | Cómo escribirlo |
|---|---|---|
| **S** Situation | Contexto: cuándo, dónde, qué escala | "During a user growth plateau for [Product] (DAU 500K+)..." |
| **T** Task | Tu rol: qué te pidieron, cuál era tu objetivo | "...led the design of a new-user activation funnel analysis..." |
| **A** Action | Qué hiciste: acciones concretas, herramientas | "...optimized 3 critical registration touchpoints + designed a 7-day retention incentive strategy..." |
| **R** Result | Qué pasó: datos, impacto, métricas | "...increasing new-user D1 retention from 32% to 45% and MAU by 18% within 3 months." |

## Verbos de acción

| Categoría | Verbos |
|---|---|
| **Liderazgo** | Led, Directed, Managed, Spearheaded, Orchestrated |
| **Creación** | Built, Designed, Developed, Created, Implemented |
| **Optimización** | Optimized, Improved, Streamlined, Enhanced, Refactored |
| **Análisis** | Analyzed, Evaluated, Assessed, Measured, Audited |
| **Resultados** | Delivered, Achieved, Generated, Drove, Produced |

## Guía de cuantificación

| Dimensión | Preguntas guía |
|---|---|
| **Escala** | ¿Cuántas personas manejabas? ¿DAU del producto? |
| **Eficiencia** | ¿Cuánto tiempo antes vs después? |
| **Crecimiento** | ¿Cambio en revenue / users / conversion rate? |
| **Costo** | ¿Dinero / headcount / tiempo ahorrado? |
| **Impacto** | ¿Usuarios servidos / clients afectados / teams cubiertos? |

## Ejemplos antes/después

**Antes:** "Responsible for user growth initiatives"
**Después:** "During a user growth plateau (DAU 500K+), led activation funnel analysis, optimized 3 registration touchpoints, increasing D1 retention from 32% to 45% and MAU by 18% in 3 months."

**Antes:** "Worked on frontend features"
**Después:** "Built 12 reusable React components adopted across 3 product teams, reducing UI development time by 40% and improving Lighthouse accessibility score from 72 to 94."
