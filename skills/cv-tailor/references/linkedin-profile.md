# LinkedIn Profile Guide - CV Tailor

Guía para adaptar tu perfil de LinkedIn como complemento del CV. No es 1:1 - LinkedIn tiene reglas distintas.

## Diferencias clave CV vs LinkedIn

| Aspecto | CV | LinkedIn |
|---|---|---|
| **Espacio** | 1-2 páginas | Ilimitado (pero nadie lee paredes de texto) |
| **Formato** | PDF, rígido | HTML, flexible |
| **Keywords** | Para ATS | Para búsqueda + algoritmo de LinkedIn |
| **Tono** | Formal, conciso | Profesional pero accesible |
| **Storytelling** | Mínimo (STAR comprimido) | Más espacio para narrativa |
| **Recomendaciones** | No aplica | Sección clave de validación social |

## Estructura del perfil

### Headline (primeros 120 caracteres)

No pongas solo tu título actual. Usá el espacio para posicionarte:

**Mala:** "Frontend Developer at X Company"
**Buena:** "Frontend Engineer | React, TypeScript, Accessibility | Building products users love"
**Mejor:** "Frontend Engineer → Fullstack | React + TypeScript + Supabase | 9 years building at scale"

Reglas:
- Incluí tu rol + stack principal + diferenciador
- Usá keywords que busca un recruiter
- Sin emojis (ocupan caracteres valiosos)

### About Section

Es tu elevator pitch. 2-3 párrafos:

1. **Quién sos** - rol, stack, años de experiencia, qué te apasiona
2. **Qué hiciste** - 2-3 logros clave con datos (STAR comprimido)
3. **Qué buscás** - próximo paso, tipo de rol, industria

**Template:**

```
[Role] with [X] years of experience building [type of products]. 
Specialized in [stack] with a focus on [differentiator].

Most recently, [achievement with data]. Before that, [another achievement].

Currently exploring [next step: roles/industries/problems].
```

### Experience Section

Acá va la diferencia más grande con el CV:

- **CV:** cada entry es STAR comprimido, 3-4 líneas
- **LinkedIn:** podés expandir un poco más, pero sin saturar

Estrategia:
- **Bullet 1:** qué hiciste (contexto + acción)
- **Bullet 2:** resultado con dato
- **Bullet 3 (opcional):** tecnología o metodología relevante
- **Media:** agregá screenshots, demos, links a proyectos

### Skills Section

- Listá 15-20 skills relevantes
- Las top 3 skills deberían estar en tu headline
- Pedí endorsements a colegas (el algoritmo pesa endorsements de conexiones fuertes)
- Priorizá skills que aparecen en JDs que te interesan

### Recommendations

- Pedí 1-2 recomendaciones de ex-jefes o clientes
- Especificá qué querés que destaquen (no "es buena persona", sino "lideró X proyecto y logró Y resultado")
- Devolvé el gesto: recomendá a otros (fortalece la red)

## Keywords para LinkedIn

LinkedIn tiene su propio algoritmo de búsqueda. Optimizá para:

| Dónde | Keywords |
|---|---|
| **Headline** | Rol + stack + seniority |
| **About** | Stack + industria + logros |
| **Experience** | Stack + metodologías + roles |
| **Skills** | Tecnologías + soft skills |

**Tip:** Mirá los perfiles de personas en roles que querés y fijate qué keywords usan en headline y about.

## Checklist de optimización

- [ ] Headline tiene rol + stack + diferenciador (≤ 120 chars)
- [ ] About section cuenta tu historia en 2-3 párrafos
- [ ] Experience tiene al menos 2 bullets con datos por entry
- [ ] Skills section tiene 15-20 skills relevantes
- [ ] Al menos 1 recomendación de un ex-jefe o colega
- [ ] Foto profesional (no selfie, no logo, no vacío)
- [ ] Banner personalizado (no el default azul)
- [ ] URL personalizada (linkedin.com/in/tunombre)
- [ ] Open to Work configurado con preferencias reales
- [ ] Actividad reciente (likes, comments, posts) - muestra que estás activo
