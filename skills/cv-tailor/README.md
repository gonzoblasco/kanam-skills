# CV Tailor

Optimización de currículums para procesos de selección.

## ¿Para qué sirve?

Para **maximizar tus chances de pasar el filtro** en una postulación. Analiza keywords contra la descripción del puesto, reescribe tu experiencia con método STAR y datos cuantificados, y verifica compatibilidad con ATS (Applicant Tracking System).

## ¿Cuándo usarlo?

- Antes de cada postulación laboral
- Cuando querés actualizar tu CV general
- Cuando no te llaman de las posiciones a las que te postulás

## ¿Cómo se usa?

Es conversacional. Le pasás tu CV y la descripción del puesto.

> "Optimizá mi CV para esta posición de Senior Frontend. Te paso el link de la busqueda y mi CV."

Hace 4 fases:

### 1. Keyword Match Analysis
Extrae keywords del JD en 3 categorías (hard skills, soft skills, industry) y genera matriz de matching. Required coverage ≥ 80% es passing.

### 2. STAR Rewriting
Reescribe cada entrada de experiencia:

| Elemento | Check |
|---|---|
| **S** Situation | Contexto, escala |
| **T** Task | Objetivo personal |
| **A** Action | Acciones concretas |
| **R** Result | Datos cuantificados |

### 3. ATS Compatibility Check
Verifica formato, layout, fuentes, estructura de secciones, densidad de keywords.

### 4. Output
- Optimization summary con scores
- CV reescrito con cambios marcados
- Recomendaciones adicionales
